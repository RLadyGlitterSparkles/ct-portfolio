Reflection

For this common task, I had to create a working clock. I found it fun and a bit challenging. I enjoyed understanding how the code worked and what the words meant and I liked coding it and a way that I further understood it was by writing out the code line by line instead of copying and pasting it. I also liked connecting it to the weather because the booklet made it extremely clear how and why things worked. Something that I found challenging was putting in the time because I missed a lesson so I didn't understand why it worked, meaning I couldn’t troubleshoot it if I had a problem. Another thing I found challenging was positioning the components onto the LED screen because I knew in theory where I wanted them to end up, but I have a perfectionist brain so I had to keep altering it slightly. Additionally, having to stop the time and restart it every time I made a change made this part extra hard. If I had more time I would have tried to create an API that linked my To Do list and my Calendar to the clock so that if I needed to update my schedule, I wouldn’t have to update it in two places. I also would have at least attempted to put in an icon to go with the weather rather than a heart or maybe put an outfit recommendation based on the weather because that would be relevant to me for my daily life, making it a more personally functional clock. From this project I have learned how to resolve issues that come up instead of freaking out. I have also learned more about coding in python and how to link Visual Studio Code to Arduino. In conclusion, this project has been an exciting and overall enjoyable project that helped me learn how to problem solve and challenge myself.
